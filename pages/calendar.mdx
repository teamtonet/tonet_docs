# Calendar

The Calendar lets you override your normal call routing on specific dates. Use it for holidays, vacations, company events, or any day where calls should go somewhere different than usual. For example, route calls to a holiday greeting during Christmas week, or send everything to voicemail during your company retreat.

Calendar entries take the highest priority in call routing - they override both [schedules](/schedule) and default [phone](/phones) destinations. See [Call Routing Priority](/phones#call-routing-priority).

Go to **Manage > Calendar** to manage your calendar events.

## Adding a Calendar Event

Click **+ New Event** in the toolbar to open the event dialog.

<Image src="/images/calendar/calendar_edit.png" alt="Edit Event dialog with title, destination, start date, and end date fields" width={600} height={500} style={{borderRadius: '8px', border: '1px solid #e0e0e0', maxWidth: '100%', height: 'auto'}}/>

Fill in the following fields:

- **Title** - A name for this event (e.g. "Christmas Week", "Labor Day", "Company Retreat")
- **Destination** - Where calls should go during this event. Opens the route picker with all available options: [Users](/users), [Groups](/groups), [Auto Attendants](/auto_attendant), Voicemail, Phone Number, and Features (like Busy tone).
- **Start date** - When this event begins (date and time picker)
- **End date** - When this event ends (date and time picker)

Click **Confirm** to create the event. It appears on the calendar immediately.

You can also click directly on a date in the calendar to create an event with that date pre-filled.

---

## Editing a Calendar Event

Click on any event in the calendar to open it for editing. The same dialog opens with the current values pre-filled. Make your changes and click **Confirm** to update.

To delete an event, click the trash icon in the bottom-left corner of the edit dialog.

## Example: Holiday Calendar

Here's how to set up holiday routing for a plumbing company:

1. [Create an auto attendant](/auto_attendant) called "Holiday Greeting" with a recording: "Thank you for calling Summit Plumbing. We're currently closed for the holiday and will return on Monday. For emergencies, press 0."
2. Go to **Calendar** and click **+ New Event**
3. Create entries for each holiday:

| Event | Start | End | Destination |
|-------|-------|-----|-------------|
| Labor Day | Sep 7, 12:00 AM | Sep 7, 11:59 PM | Busy |
| Thanksgiving | Nov 26, 12:00 AM | Nov 27, 11:59 PM | Busy |
| Christmas Week | Dec 24, 12:00 AM | Dec 26, 11:59 PM | Holiday Greeting (IVR) |
| Company Retreat | Aug 15, 12:00 AM | Aug 15, 11:59 PM | Busy |

During these dates, all calls to phone numbers with a calendar assigned are routed to the specified destination, regardless of their [schedule](/schedule) or default routing.

<Callout type="info">
  **Busy vs. IVR** - Setting the destination to "Busy" plays a busy tone and disconnects. For a better caller experience, create an [Auto Attendant](/auto_attendant) with a holiday greeting so callers know you're closed, when you'll be back, and what to do in an emergency.
</Callout>

## Assigning the Calendar to a Phone Number

Calendar events only affect phone numbers that have a calendar assigned:

1. Go to **[Phones](/phones)** and click the number you want to configure
2. In the **Configure** tab, set the **Calendar** dropdown to your calendar
3. On any date that matches a calendar event, calls to that number are routed to the event's destination

<Callout type="info">
  **Routing Priority:** Calendar has the highest priority. If today matches a calendar event, that destination is always used - even if the phone number also has a [schedule](/schedule) configured. The priority order is: Calendar > Schedule > Go To (default). See [Call Routing Priority](/phones#call-routing-priority) for full details.
</Callout>
