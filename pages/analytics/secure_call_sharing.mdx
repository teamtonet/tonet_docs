# Call Sharing

Share call recordings and details with anyone using secure, unique links. Generate a public link to a specific call - complete with the recording and call analytics - and send it to a team member, supervisor, or client. No login required for recipients.

<Image src="/images/analytics/secure_call_sharing.png" alt="Shared call details page showing recording player, time details, contact information, and call status" width={1179} height={539} style={{borderRadius: '8px', border: '1px solid #e0e0e0', maxWidth: '100%', height: 'auto'}}/>

The shared page includes:

- **Recording player** - Full call recording with playback controls
- **Time Details** - Date, time, and call duration
- **Contact Information** - From and To phone numbers
- **Call Status** - Answered, missed, or busy, and whether the call was inbound or outbound

---

## Sharing a Call

1. Go to [Call History](/analytics/call_logs)
2. Find the call you want to share
3. Click the **share icon** on that call's row. The icon is grey if the call hasn't been shared before, or orange if a public link already exists.
4. In the dialog, click **Create Public Link**
5. The link appears in the **Public Link** field. Click **Copy Public Link** to copy it to your clipboard.
6. Send the link to anyone - they can view the call details and listen to the recording without logging in.

## Managing Shared Links

Once a call has a public link, clicking the share icon opens the dialog with the existing link and two options:

<Image src="/images/analytics/public_link_modal.png" alt="Share dialog showing the public link with Copy and Remove options" width={582} height={208} style={{borderRadius: '8px', border: '1px solid #e0e0e0', maxWidth: '100%', height: 'auto'}}/>

- **Copy Public Link** - Copy the URL to share it again
- **Remove Public Link** - Deactivate the link immediately. Anyone who had the link can no longer access the call. The share icon on the call row turns back to grey.

If you remove a link and need to share the call again later, click **Create Public Link** to generate a new URL. The old link stays permanently deactivated.

<Callout type="info">
  Each link uses a unique, randomly generated ID that can't be guessed. Only people you send the link to can access the call.
</Callout>
