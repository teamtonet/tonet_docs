# GXP2130 Configuration

<Callout type="warning">
  The GXP series has been replaced by the GRP series. If you are purchasing a new phone, consider the [GRP2612](/ip_phones/grandstream/grp2612).
</Callout>

<Callout emoji="⚠">
  Firmware 1.0.8.56 or newer required.
</Callout>

## SIP Registration

* Find the IP-address of your IP Phone. Press the Menu Key in the middle of the Arrow Pad.
![main_menu](/images/ip_phones/grandstream/main_menu_2130.png)
* Navigate to Status and Select "Network Status"
* Take note of the IPv4 Address displayed

* Navigate to the IP Phones web-interface using a browser on your PC.
* Type the IP-Address of the IP Phone in the browser's address bar.

![browser-address-bar](/images/ip_phones/grandstream/browser_address_bar.png)

* Login to the IP Phones interface (Default username and password is admin / admin)

![login-screen](/images/ip_phones/grandstream/login_screen_2130.png)

* Navigate to Accounts - Account 1 - General Settings

![account-1-navigation](/images/ip_phones/grandstream/account_navigation.png)

* Set the Account to Active and fill out SIP Server, SIP User ID, Authenticate ID, Authenticate Password, and Name as per the information
you recieved from Support.

![account-1-settings](/images/ip_phones/grandstream/account_settings.png)

* Click on Save and Apply

## STUN Configuration
<Callout emoji="⚠">
  STUN configuration is required to avoid audio issues such as one way audio.
</Callout>

* Click on Network Settings in the left hand side menu.

![network-settings-menu](/images/ip_phones/grandstream/network_settings_menu.png)

* In the Nat Traversal drop-down menu select STUN

* Click on Save and Apply

* In the top menu select Settings - General Settings

![general-settings-menu](/images/ip_phones/grandstream/general_settings_menu.png)

* Add "stun.tonet.ai:3478" in the "STUN Server" field.

![general-settings](/images/ip_phones/grandstream/general_settings.png)

* Click on Save and Apply
