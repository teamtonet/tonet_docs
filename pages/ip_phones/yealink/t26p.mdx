# Yealink T-26P Configuration

## SIP Registration

* Find the IP-address of your IP Phone. Press the Menu Key in the middle of the Arrow Pad.
![main_menu](/images/ip_phones/yealink/main_menu.png)
* Under "status", as long as the phone has an active network connection it will show the phone's IP-Address.
* Take note of the IP-Address displayed

* Navigate to the IP Phones web-interface using a browser on your PC.
* Type the IP-Address of the IP Phone in the browser's address bar.

![browser-address-bar](/images/ip_phones/yealink/browser_address_bar.png)

* Login to the IP Phones interface (Default username and password is admin / admin)

![login-screen](/images/ip_phones/yealink/login_screen.png)

* Navigate to Account, select Account 1

* Set Line Active to Enabled and fill out **Display Name**, **Register Name**, **User Name**, **Password** and **Server Host & Port** as per the information
you recieved from Support. Set **NAT** to STUN and set the **Stun Server** to: stun.tonet.ai.

![account-1-settings](/images/ip_phones/yealink/account_settings.png)

* Click on Confirm

* Register Status should switch to show "Registered". If it doesn't, reboot the phone by going to Settings - Upgrade - Reboot.

![register-status](/images/ip_phones/yealink/register_status.png)

![reboot](/images/ip_phones/yealink/reboot.png)
