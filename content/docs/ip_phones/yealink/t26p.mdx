Setting up a different phone? Pick it on [Desk phones](/ip_phones).

The T26P is an older Yealink phone with 3 lines. Its web page signs in as **admin** / **admin** by default. Yealink stopped selling it in 2015 and ended support at the end of 2020, so it gets no more firmware.

## What you need

- The phone, connected to your router or network switch with a network cable in the port marked **Internet**. It takes power from the cable (PoE) or from a power adapter, which doesn't come in the box. The T26P has no Wi-Fi.
- A computer on the same network.
- The person's [SIP details](/ip_phones#find-your-sip-details): **User Name**, **Password** and **Domain**.

## Find the T26P IP address

Press **OK** on the phone while it's idle. The status screen shows the **IP Address**. You can also go to **Menu › Status**.

## T26P default password

The username is **admin** and the password is **admin**.

1. On the computer, open a browser and type the phone's IP address in the address bar, like `192.168.1.50`.
2. Sign in with **admin** and **admin**, and click **Confirm**.

To change the password later, go to **Security › Password**.

**admin doesn't work?** Someone changed the password. A [factory reset](#factory-reset-the-t26p) brings back **admin**, but on the T26P both ways to reset ask for the admin password first. Ask whoever set the phone up, or the provider it came from.

## Enter your Tonet line

On the T26P, STUN is set on the same page as the line.

1. On the phone's web page, go to **Account › Register**. In the **Account** list, pick **Account 1**.
2. Fill in:

| Field | Enter |
|---|---|
| **Line Active** | **Enabled** |
| **Label** | What the phone screen shows for this line, like the person's name |
| **Display Name** | The person's name |
| **Register Name** | The **User Name** from SIP Information |
| **User Name** | The **User Name** from SIP Information |
| **Password** | The **Password** from SIP Information |
| **NAT** | **STUN** |
| **STUN Server** | `stun.tonet.ai`, with `3478` in the **Port** box next to it |
| **Server Host** (under **SIP Server 1**) | The **Domain**, up to the colon |
| **Port** (next to **Server Host**) | The number after the colon in **Domain** |

3. Click **Confirm**.

For example, if **Domain** shows `pbx.example.com:5080`, enter `pbx.example.com` in **Server Host** and `5080` in **Port**.

## Check that it registered

- On the web page, **Account › Register** shows **Register Status** at the top. It should say **Registered**. The **Status** page lists each account's status too.
- On the phone, the line's label shows an icon for registered, registering or register failed.

Not registered? Restart the phone: on the web page, go to **Settings › Upgrade** and click **Reboot**. Still not registered? See [Register Failed](/ip_phones/troubleshooting#register-failed).

## Factory reset the T26P

A factory reset erases every setting on the phone, including your line, and sets the admin password back to **admin**.

**From the phone:** go to **Menu › Settings › Advanced Settings** (enter the admin password, **admin** by default), scroll to **Reset to Factory** and press **Enter**. When it asks **Reset to factory settings?**, press **OK**.

**From the web page:** go to **Settings › Upgrade** and click **Reset to Factory**. Click **OK** to confirm.

The reset takes a few minutes. Don't unplug the phone until it has started up again.

## Update the firmware

The T26P's last firmware is 6.73.0.50.

1. Download it from [support.yealink.com](https://support.yealink.com), where the T26P is under **EOL Product**.
2. On the phone's web page, go to **Settings › Upgrade**. Next to **Select and Upgrade Firmware**, click **Browse** and pick the `.rom` file.
3. Click **Upgrade**, then **OK**. It takes about 5 minutes. Don't close the browser or unplug the phone until it restarts.
