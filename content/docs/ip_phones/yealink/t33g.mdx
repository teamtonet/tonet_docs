The T33G has a 2.4-inch color screen and 4 line keys. You set it up from its web page, on a computer on the same network. The web page's default sign-in is **admin** / **admin**.

Bought your T33G from Tonet? It arrives with your line already loaded. Plug it in and go to [Check that it registered](#check-that-it-registered).

## What you need

- The phone, connected to your router or network switch with a network cable. It takes power from the cable (PoE) or from a Yealink power adapter. The T33G has no Wi-Fi.
- A computer on the same network.
- The person's [SIP details](/ip_phones#find-your-sip-details): **User Name**, **Password** and **Domain**.

## Find the T33G IP address

Press **OK** on the phone while it's idle. The status screen shows the IP address. You can also go to **Menu › Status**.

## T33G default admin password

The username is **admin** and the password is **admin**. Current firmware makes you choose a new password the first time you sign in, and again after a factory reset.

1. On the computer, open a browser and go to `https://` followed by the phone's IP address, like `https://192.168.1.50`.
2. If the browser warns that the connection isn't private, click **Advanced**, then continue to the address.
3. Sign in with **admin** and **admin**.
4. If asked, set a new password and write it down. It needs at least 8 characters and at least three of these: lowercase letters, uppercase letters, numbers, symbols. No more than 3 of the same character in a row, and it can't be the username.

**admin doesn't work?** The password was changed. A [factory reset](#factory-reset-the-t33g) sets it back to **admin**. If the phone came from another provider, it may run that provider's own firmware and password: Yealink says to ask that provider. If **admin** still fails after a reset, follow Yealink's [password reset and recovery](https://support.yealink.com/document-detail/b4da2b33210c49dcbecffd65683a45bb) steps.

## Enter your Tonet line

1. On the phone's web page, go to **Account › Register**. In the **Account** list, pick **Account 1**.
2. Fill in:

| Field | Enter |
|---|---|
| **Line Active** | **Enabled** |
| **Label** | What the phone screen shows for this line, like the person's name |
| **Display Name** | The person's name |
| **Register Name** | The **User Name** from SIP Information |
| **User Name** | The **User Name** from SIP Information |
| **Password** | The **Password** from SIP Information |
| **Server Host** (under **SIP Server 1**) | The **Domain**, up to the colon |
| **Port** (under **SIP Server 1**) | The number after the colon in **Domain** |

3. Click **Confirm**.

For example, if **Domain** shows `pbx.example.com:5080`, enter `pbx.example.com` in **Server Host** and `5080` in **Port**.

## Turn on STUN

1. Go to **Network › NAT**. Under **STUN**, set **Active** to **Enabled**. Enter `stun.tonet.ai` in **STUN Server** and `3478` in **STUN Port**. Click **Confirm**.
2. Go to **Account › Register**, pick **Account 1**, and set **NAT** to **STUN**. Click **Confirm**.

The account's **NAT** setting only works once STUN is active in **Network › NAT**.

## Check that it registered

- On the web page, **Account › Register** shows **Register Status**. It should say **Registered**.
- On the phone, the line's icon is green when registered, yellow while registering, and gray if registration failed.

Not registered after a minute? See [Register Failed](/ip_phones/troubleshooting#register-failed).

## Factory reset the T33G

A factory reset erases every setting on the phone, including your line, and sets the admin password back to **admin**.

**From the phone:**

- Press and hold **OK** while the phone is idle. When it asks **Reset to factory setting?**, select **OK**.
- Or go to **Menu › Advanced › Reset Config › Reset to Factory Settings** and select **OK**. **Advanced** asks for the admin password.

**From the web page:** go to **Settings › Upgrade** and click **Reset to Factory**. Click **OK** to confirm.

The reset takes a few minutes. Don't unplug the phone until it has started up again.

## Update the firmware

1. Download the T33G's latest firmware from [support.yealink.com](https://support.yealink.com): find the phone, then its **Firmware & Release Note** section. The file ends in `.rom`.
2. On the phone's web page, go to **Settings › Upgrade › Upgrade Firmware**, pick the file, and start the upgrade.
3. Don't close the browser or unplug the phone until it restarts.

<Callout type="warn">
  Going from version 86 to version 87 firmware (124.86 to 124.87) on the web page fails with **ROM invalid**. Install 124.86.0.118 first, then version 87. Once on version 87, the phone can't go back to 86.
</Callout>
