Any desk phone that supports SIP works with Tonet: Yealink, Grandstream, Polycom, Cisco and others. You copy four details from the dashboard into the phone's web page: **User Name**, **Password**, **Domain** and **STUN**.

## Find your SIP details

Each person has their own SIP details, in the dashboard:

![The SIP Information box: User Name, Password, Domain and STUN, each with a copy button](/images/users/sip-information.webp)

1. Go to **Manage › Users**.
2. Click the person, or open their **⋯** menu and click **View**.
3. Find the **SIP Information** box. Each value has a copy button. The password is hidden: click the eye to show it.

| In SIP Information | What it is | Where it goes in the phone |
|---|---|---|
| **User Name** | The line's ID: a `u` and a number, like `u12345`. It isn't the extension. | The user name, and the authentication ID if the phone asks for one |
| **Password** | The line's password | The password |
| **Domain** | Your phone server and its port, written `server:port` | The SIP server. Grandstream phones take the whole value. Yealink phones split it into **Server Host** and **Port**. |
| **STUN** | `stun.tonet.ai:3478` | The STUN server. See [STUN server and port](#stun-server-and-port). |

Copy the whole **Domain**, including the number after the colon. That number is your port.

## Who can see SIP details

| Role | Sees SIP Information for |
|---|---|
| **Owner** | Everyone |
| **Manager** | Everyone except the owner |
| **Administrator** | Only themselves |
| **Regular User** | Nobody. Regular users can't open **Manage**, so ask the owner or a manager. |

Each line on a desk phone signs in as one person. To set up a phone for someone new, [add them in Users](/users#add-a-person) first.

## STUN server and port

Tonet's STUN server is `stun.tonet.ai`, port `3478`. The dashboard shows them together as `stun.tonet.ai:3478`.

Turn STUN on in every desk phone, and set the phone's account to use it. For one-way audio or no audio on a device behind a router, the first fix Grandstream lists is turning on STUN.

Port 3478 is the standard STUN port, and the default STUN port on Yealink phones.
