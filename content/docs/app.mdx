The desktop app is Tonet in its own window. It keeps your line on all day: close the window and calls still ring.

Everything in the dashboard works in the app, because the app opens the same dashboard. When the dashboard gets new features, the app has them too.

On your cell, use the [Tonet phone app](/phone-app) for iPhone and Android.

## Get the app

| Computer | Available? |
|---|---|
| Linux: Ubuntu, Debian and most 64-bit systems | Yes. Download it at [tonet.ai/download](https://tonet.ai/download). |
| Windows 10 and 11 | Not yet. Coming soon. |
| Mac | Not yet. Coming soon. |

On Windows or Mac, use Tonet in your browser at [dashboard.tonet.ai](https://dashboard.tonet.ai) for now.

## Install on Linux

**Ubuntu or Debian:**

1. Go to [tonet.ai/download](https://tonet.ai/download) and download the `.deb` file.
2. Open a terminal and run:

```bash
sudo apt install ~/Downloads/Tonet-amd64.deb
```

3. Open **Tonet** from your apps.

**Other 64-bit Linux:** download the **AppImage** from the same page, make it executable, and run it.

Sign in with the same email and password, or Google, that you use for the dashboard.

## What the app adds

| Feature | What it does |
|---|---|
| Rings with the window closed | Closing the window hides it. Tonet waits in your tray and calls still ring. |
| Call window on top | A small window shows who's calling. Answer and take notes over whatever you're working in. |
| New call from anywhere | Press **Ctrl+Shift+D** in any app to start a call. |
| Starts when you sign in | On by default, so your line is on before your first call. |
| Pause notifications | Texts, chat and voicemail wait for an hour. Calls still ring. |

## The tray menu

Click the Tonet icon in your tray:

| Item | What it does |
|---|---|
| **Set status** | Changes your status, like Away or Busy |
| **Open Tonet** | Shows the window |
| **New call** | Opens the phone to dial |
| **Pause notifications for 1 hour** | Quiets texts, chat and voicemail. Calls still ring. |
| **Report an issue…** | Sends us a problem report with the app's version filled in |
| **Start Tonet when I sign in** | Turns starting at sign-in on or off |
| **Quit Tonet (stops ringing here)** | Closes the app. Calls stop ringing on this computer. |

When a new version is out, the menu shows **Update to Tonet** with the version number.

<Callout type="info">
  On Linux, the tray icon needs the AppIndicator extension. Ubuntu turns it on by default. Linux notifications don't have Answer or Decline buttons, so Tonet shows its own ringing window instead.
</Callout>
