Verified Caller ID lets calls from a Tonet number show another number you own, like your office line while it's [being ported](/phones/port_number). To prove the number is yours, you answer a call from Tonet and type a code.

<Callout type="info">
  Only some accounts have this. If **Manage › Phones** has no **Verified Caller ID** tab, your account doesn't have it.
</Callout>

Owners, managers and admins can verify numbers and set caller ID.

## Verify a number

1. Go to **Manage › Phones** and open the **Verified Caller ID** tab.
2. Click **Add a new Caller ID**.
3. Type the **Phone Number**, and a **Friendly Name** to recognize it, like "Office line". Click **Next**.
4. A code shows on screen, and Tonet calls the number. Answer, and type the code on the phone's keypad.
5. When it works, the window says the number has been verified.

Can't answer calls on that number right now? Forward it to a phone you can answer, then try again.

## What each status means

| Status | Means |
|---|---|
| **Verified** | Ready to use as caller ID |
| **Pending** | The verification call hasn't finished |
| **Verification failed** | The number wasn't verified |

For **Pending** or **Verification failed**, click **Resend verification call**. The window opens with the number filled in. Click **Next** for a new call and code.

## Show the number on your calls

1. Go to **Manage › Phones** and click the Tonet number you call from.
2. Open the **Route & settings** tab.
3. In **Caller ID**, pick the verified number. Only numbers marked **Verified** are listed.
4. Click **Save Settings**.

Calls from that Tonet number now show the verified number. You can use one verified number on several Tonet numbers.

This only changes outgoing calls. Calls to your Tonet number come in as before.

## Stop showing a verified number

There's no button to remove a number from the list. To stop showing it, set **Caller ID** back to your Tonet number, marked **This number (default)**, and click **Save Settings**.
